# OpenQuest 🎯

Tu aventura financiera comienza aquí.

## Descripción

OpenQuest es una aplicación de finanzas gamificada que hace divertido el ahorro y la inversión. Completá misiones, ganá experiencia, subí de nivel y alcanzá la libertad financiera.

## Conceptos Clave

- **Interés Compuesto:** La bola de nieve que hace crecer tu dinero exponencialmente
- **Inflación:** El enemigo que debés derrotar para proteger tu poder de compra
- **Fondo de Emergencia:** Tu kit de supervivencia para imprevistos (6-9 meses de gastos)
- **Riesgo y Perfil:** Definí tu clase de personaje (conservador, moderado, agresivo)

## Productos Disponibles

- 💳 Cuenta de Débito Remunerada (12% anual)
- 🔒 Apartados / Subcuentas para metas
- 💰 Tarjetas de Crédito con cashback
- 📊 ETFs (Fondos cotizados del S&P 500)
- 🤖 Robo-advisor automático

## Características

- ✅ Onboarding ultrarrápido con autenticación biométrica
- ✅ Dashboard con barra de salud financiera (XP)
- ✅ Sistema de misiones y recompensas
- ✅ Insignias y rachas de ahorro
- ✅ Ahorro automático por redondeo
- ✅ Zona de inversión desbloqueable por nivel

## Instalación

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Construir para producción
npm run build
```

## Tech Stack

- React 18
- Vite
- CSS3 con variables
